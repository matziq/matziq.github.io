The prompting pattern (GCSE)

One short pattern, then use it everywhere. Every starting prompt in this guide follows it.

G

Goal

What should be accomplished — name the action and the deliverable.

C

Context

Who it is for, why it matters, what constraints apply.

S

Source

The exact content to use — the named table, the selected file, the pasted text. A prompt cannot grant access to a file you cannot open.

E

Expectation

Format, scope, quality checks, boundaries.

Weak

"Analyze this."

Stronger

"Compare P1 and P2 revenue and spend using CampaignResults. Show totals and percentage changes, identify missing evidence, and do not infer causation."

Best-practice loop

Frame the task → ground it in a source → inspect the answer → challenge one weakness → refine. Start a new chat when switching unrelated tasks. GCSE is a scaffold, not a required syntax — after the first prompt, use natural follow-ups.

MANUAL EXCEL FALLBACK

B2: =SUMIF(CampaignResults[Period],A2,CampaignResults[Revenue_USD])

00 / Researcher — start it now
Microsoft 365 Copilot app · AgentsDeep-dive
Run→Check→Improve

Where to run it

Microsoft 365 Copilot app → Agents → Researcher. Researcher takes longer by design; it may ask a clarifying question — answer it or say "Go ahead", then move on to Outlook. Scope it to the web only so no work content appears on a shared screen.

Start this before anything else. Come back for the second prompt after Analyst, before you write the Word brief.

Starting prompt (GCSE)

Web-only scope, explicit structure, and a ban on invented citations make the report checkable.

Goal: Build a short measurement checklist for evaluating a small beauty-retail marketing test.

Context: I am practicing evidence-based planning for a fictional campaign called Studio Launch. I need a checklist I can drop into a one-page decision brief, not claims about any real company.

Source: Public web sources only, preferably published in the past 12 months. Do not use my work files, email, meetings, or chats.

Expectation: A report under 500 words with three parts: (1) five metrics to check before recommending a next test, each with a one-line definition and the data it requires; (2) what a revenue-and-spend table alone can and cannot tell you; (3) a source list with title, publisher, date, and link. Distinguish evidence from advice. Do not invent citations.

Second prompt (when you return)

Turns the checklist into something the Studio Launch table can actually feed.

For each of the five metrics, mark whether it can be calculated from a table containing only Period, Channel, Category, Revenue and Spend. Flag anything that is your inference rather than a source statement.

Success check

Five metrics, each with a definition and required data; every citation opens and matches; the report says plainly what revenue and spend alone cannot answer.

Feature tips

  • Researcher lives under Agents in Copilot Chat.
  • It draws on the web and, if you allow it, your work content — be specific and define the scope (web, work, or both).
  • It asks clarifying questions before it runs.
  • The report is structured and cited and can be sent on to a document.

If it's not available

Run the same prompt in Copilot Chat with web grounding and label it a Chat fallback, not research.

Facilitator cue — Deep-dive. If the room falls behind, Analyst follow-ups and the Researcher section of the Word brief become take-home work; the Outlook → Excel → Word → PowerPoint chain is the core path.

01 / Outlook
OutlookCore
Run→Check→Improve

Where to run it

Outlook → Copilot (Draft with Copilot / Copilot pane). Paste the synthetic thread into the prompt — the starting prompt below already contains it. Do not send anything.

For real threads later, use the thread summary at the top of a conversation and Draft with Copilot in a reply.

Starting prompt (GCSE)

Combines summarization with a bounded draft while protecting the meaning of the original messages. The Source line carries the full synthetic thread.

Goal: Summarize this email thread and prepare a reply I can review.

Context: I am coordinating the fictional Studio Launch review. I need to preserve uncertainty and avoid promising dates or approvals.

Source: SYNTHETIC EMAIL THREAD - fictional roles, not actual correspondence.
Subject: Studio Launch - next test review
September 14, 2026 / Campaign Lead:
Please prepare a recommendation for the next four-week test. USD 8,000 is a proposed spending ceiling, not an approval. Use the P1/P2 results.
September 15, 2026 / Creative Lead:
The revised visual concept is not ready. I will provide a status update on September 18, not a final delivery commitment.
September 16, 2026 / Analytics Lead:
P2 revenue is higher, but spend also increased. We have no margin or attribution data and cannot infer causation. Please show spend alongside revenue.
September 17, 2026 / Operations Lead:
The vendor delivery date is unconfirmed. Please request a delivery estimate before setting the test start date.
September 17, 2026 / Campaign Lead:
Bring a short decision brief to our September 21 review. Do not announce a start date or send external communications until approval.

Expectation: Return decisions, open questions, and an action table with role, action, and explicitly stated due date. Use 'not specified' for missing dates. Then draft a reply under 150 words requesting the vendor estimate and creative status. Do not send anything or imply approval.

Second prompt

Targets the two most likely summarization errors: a status update read as a deadline, and a proposal read as an approval.

Audit your action table against the messages. Distinguish the September 18 status update from a creative delivery deadline, and separate the proposed USD 8,000 ceiling from approved spending. Correct any overstatement.

Third prompt

Produces a concise reply without unsupported commitments.

Rewrite the draft in 100 words or fewer with two numbered requests and a final sentence that leaves the test start date unconfirmed. Keep the tone clear and collaborative. Do not send it.

Success check

  • September 18 is a status update only.
  • Vendor delivery and start date are unconfirmed.
  • The USD 8,000 ceiling is not approved.
  • Nothing sent.

Feature tips

  • Summarize a thread in one click.
  • Draft with Copilot inside a reply; adjust tone and length before inserting.
  • Coaching by Copilot reviews your own draft for tone, clarity and sentiment.
  • A fluent draft is not a faithful draft — read it against the thread.

If it's not available

Run the prompt in Copilot Chat and label it a Chat fallback.

02 / Excel
ExcelCore
Run→Check→Improve

Where to run it

Paste the TSV from the practice kit into A1 of your OneDrive-saved workbook, format A1:E9 as a table with headers, name it CampaignResults, then open Copilot in Excel.

Starting prompt (GCSE)

Moves from a natural-language request to reviewable workbook calculations, not just a plausible narrative.

Goal: Compare P1 and P2 campaign performance and create a small summary with a chart in this workbook.

Context: These are synthetic, equal-length test periods. I need a cautious recommendation, not a claim that media caused revenue.

Source: Use only the CampaignResults table in this workbook, with columns Period, Channel, Category, Revenue_USD, and Spend_USD. Do not use other sheets or outside information.

Expectation: Validate eight rows, numeric amounts, and period labels. Create a Summary sheet with total revenue, total spend, and revenue divided by spend for each period. Calculate P2-versus-P1 dollar and percentage changes. Show formulas, define percentage denominators, and handle division by zero explicitly. Add a revenue-and-spend column chart. Preserve the source table and explain all changes.

Second prompt

Catches aggregation mistakes and draws attention to the one meaningful exception.

Reconcile each total to the source rows and list the formulas or cell references used. Identify which Channel/Category combination has declining revenue despite increased spend. Do not average row-level ratios to calculate the overall revenue/spend ratio.

Success check

  • P1 21,000 / 5,250; P2 24,000 / 6,050.
  • +14.29% revenue vs +15.24% spend.
  • Ratio 4.0000x → 3.9669x.
  • Retail event / Lip is the exception.
  • Source cells unchanged.

Feature tips

  • Copilot in Excel can add formula columns, highlight and sort, propose charts and pivots, and explain a formula.
  • New edits are linked so you can jump to what Copilot changed, and Show Changes attributes AI-made edits (rollout varies).
  • Python in Excel is optional — the core lab uses ordinary formulas.

If it's not available

Ask Copilot for exact formulas and chart steps and perform them manually (see Manual Excel fallback in the practice kit). A chat description is not a completed workbook.

03 / Analyst
Microsoft 365 Copilot app · AgentsDeep-dive
Run→Check→Improve

Where to run it

Save the workbook. Microsoft 365 Copilot app → Agents → Analyst → + → Attach content → pick the Studio Launch workbook from OneDrive.

Starting prompt (GCSE)

Asks the agent to argue against the headline and to show its working.

Goal: Challenge the headline that Studio Launch P2 outperformed P1.

Context: Synthetic test data for two equal four-week periods. Before I write a decision brief I want to know where spend grew faster than revenue.

Source: Only the attached workbook, table CampaignResults (Period, Channel, Category, Revenue_USD, Spend_USD; 8 rows). Do not use other files or outside information.

Expectation: (1) Totals by Period. (2) Revenue/spend ratio by Period and by Period and Channel, calculated from totals, not averaged row ratios. (3) Every Channel/Category combination where the percentage change in spend exceeded the percentage change in revenue. (4) One chart comparing revenue change and spend change by Channel/Category. Show your calculation steps. State clearly that this data cannot show profit, incremental return, or causation.

Second prompt

Turns the analysis into brief-ready language with explicit evidence gaps.

List the data this file does not contain that I would need before claiming profit, incremental return, or that media drove revenue. Then write two cautious findings and two open questions, each with exact values and baselines.

Success check

  • Overall 4.0000x → 3.9669x; Online 4.0000x → 4.2727x; Retail event 4.0000x → 3.6000x.
  • Exactly one combination flagged — Retail event / Lip (revenue -8.33%, spend +22.22%).
  • The calculation steps are visible.

Feature tips

  • Analyst runs real calculations (Python) on the attached file and lets you expand the reasoning to see the steps and code.
  • It works across xlsx/csv and multiple files.
  • Results can be sent to a Page, Word or copied into PowerPoint.
  • Excel Copilot works inside the open workbook; Analyst works on attached files in Chat — use both.

If it's not available

Attach the workbook in Copilot Chat and run the same prompt; label it a Chat fallback and note that the reasoning steps may not be visible.

05 / PowerPoint
PowerPointCore
Run→Check→Improve

Where to run it

PowerPoint → Copilot → Create a presentation from a file → select the Word brief you just saved (or paste the brief and results into the prompt if file selection is unavailable).

Starting prompt (GCSE)

Gives the deck a decision structure and an explicit evidence boundary before any design polish.

Goal: Create a five-slide decision brief for the next fictional Studio Launch test from the selected Word document.

Context: The audience is a cross-functional planning team. The goal is to choose the next question to test, not authorize launch spending.

Source: Use only the selected Word document. Do not add outside facts.

Expectation: Five slides: decision needed; results; the underperforming segment; what the data cannot tell us; next-test proposal and requests. One message per slide, at most three short points, and speaker notes that distinguish facts from assumptions. Label all data synthetic. Do not invent a launch date, product claim, or approval.

Second prompt

Protects the central takeaway from being oversimplified.

Revise the results slide to emphasize that revenue rose 14.29% while spend rose 15.24%. Keep both baselines visible (USD 21,000 → 24,000; USD 5,250 → 6,050). Add a note that revenue/spend is not profit, and remove any claim that the campaign caused the change.

Third prompt

Turns the ending into a realistic decision conversation.

Tighten the final slide to one decision question and two possible next-test directions. Label both as hypotheses, preserve the unapproved USD 8,000 ceiling, and add a speaker note listing the information required before approval.

Success check

  • Five slides; synthetic label.
  • 14.29% vs 15.24% with baselines.
  • No causal or profit claim.
  • No approved budget or start date.
  • Speaker notes present.

Feature tips

  • Create from a file (Word, or reference an email on Windows).
  • Add a slide about a topic; rewrite or shorten a slide; Designer for layout.
  • Speaker notes generated with the deck.
  • Ask Copilot to summarize or find key slides in an existing deck.
  • An attractive deck can still misstate the source — check every number.
