Manual Excel fallback

Use when Copilot in Excel cannot edit the workbook. A chat description is not a completed workbook.

MANUAL EXCEL FALLBACK
On a Summary sheet, put P1 in A2 and P2 in A3.
B2: =SUMIF(CampaignResults[Period],A2,CampaignResults[Revenue_USD])
C2: same pattern with Spend_USD; fill down.
D2: =IF(C2=0,NA(),B2/C2)
Revenue change: =B3-B2
Percentage change: =IF(B2=0,NA(),(B3-B2)/B2); repeat for spend.
Insert a clustered column chart from Period, Revenue, Spend.
Function names/separators vary by locale.

00 / Researcher — start it now

Where to run it

Microsoft 365 Copilot app → Agents → Researcher. Researcher takes longer by design; it may ask a clarifying question — answer it or say "Go ahead", then move on to Outlook. Scope it to the web only so no work content appears on a shared screen.

Starting prompt (GCSE)

Goal: Build a short measurement checklist for evaluating a small beauty-retail marketing test.

Context: I am practicing evidence-based planning for a fictional campaign called Studio Launch. I need a checklist I can drop into a one-page decision brief, not claims about any real company.

Source: Public web sources only, preferably published in the past 12 months. Do not use my work files, email, meetings, or chats.

Expectation: A report under 500 words with three parts: (1) five metrics to check before recommending a next test, each with a one-line definition and the data it requires; (2) what a revenue-and-spend table alone can and cannot tell you; (3) a source list with title, publisher, date, and link. Distinguish evidence from advice. Do not invent citations.

Second prompt (when you return)

For each of the five metrics, mark whether it can be calculated from a table containing only Period, Channel, Category, Revenue and Spend. Flag anything that is your inference rather than a source statement.

Success check

Five metrics, each with a definition and required data; every citation opens and matches; the report says plainly what revenue and spend alone cannot answer.

  • Ratio 4.0000x → 3.9669x.

03 / Analyst

Where to run it

Save the workbook. Microsoft 365 Copilot app → Agents → Analyst → + → Attach content → pick the Studio Launch workbook from OneDrive.

Starting prompt (GCSE)

Goal: Challenge the headline that Studio Launch P2 outperformed P1.

Context: Synthetic test data for two equal four-week periods. Before I write a decision brief I want to know where spend grew faster than revenue.

Source: Only the attached workbook, table CampaignResults (Period, Channel, Category, Revenue_USD, Spend_USD; 8 rows). Do not use other files or outside information.

Expectation: (1) Totals by Period. (2) Revenue/spend ratio by Period and by Period and Channel, calculated from totals, not averaged row ratios. (3) Every Channel/Category combination where the percentage change in spend exceeded the percentage change in revenue. (4) One chart comparing revenue change and spend change by Channel/Category. Show your calculation steps. State clearly that this data cannot show profit, incremental return, or causation.

Second prompt

List the data this file does not contain that I would need before claiming profit, incremental return, or that media drove revenue. Then write two cautious findings and two open questions, each with exact values and baselines.

Success check

  • Overall 4.0000x → 3.9669x; Online 4.0000x → 4.2727x; Retail event 4.0000x → 3.6000x.
  • Exactly one combination flagged — Retail event / Lip (revenue -8.33%, spend +22.22%).
  • The calculation steps are visible.

05 / PowerPoint

Where to run it

PowerPoint → Copilot → Create a presentation from a file → select the Word brief you just saved (or paste the brief and results into the prompt if file selection is unavailable).

Starting prompt (GCSE)

Goal: Create a five-slide decision brief for the next fictional Studio Launch test from the selected Word document.

Context: The audience is a cross-functional planning team. The goal is to choose the next question to test, not authorize launch spending.

Source: Use only the selected Word document. Do not add outside facts.

Expectation: Five slides: decision needed; results; the underperforming segment; what the data cannot tell us; next-test proposal and requests. One message per slide, at most three short points, and speaker notes that distinguish facts from assumptions. Label all data synthetic. Do not invent a launch date, product claim, or approval.

Second prompt

Revise the results slide to emphasize that revenue rose 14.29% while spend rose 15.24%. Keep both baselines visible (USD 21,000 → 24,000; USD 5,250 → 6,050). Add a note that revenue/spend is not profit, and remove any claim that the campaign caused the change.

Third prompt

Tighten the final slide to one decision question and two possible next-test directions. Label both as hypotheses, preserve the unapproved USD 8,000 ceiling, and add a speaker note listing the information required before approval.

Success check

  • Five slides; synthetic label.
  • 14.29% vs 15.24% with baselines.
  • No causal or profit claim.
  • No approved budget or start date.
  • Speaker notes present.
