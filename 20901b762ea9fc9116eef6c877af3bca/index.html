01 · What a skill is

A skill is a reusable set of instructions that tells Copilot how to complete a repeatable task. If you ask Copilot for the same thing often, turn that request into a skill.

Prompt

One request, typed each time. Good for one-off work.

Skill

Saved steps Copilot reuses on demand, or automatically when your request matches the skill’s description.

Where skills come from

  • Built-in skills provided by Microsoft, such as @clean-data and @chart-design in Excel.
  • Custom skills you create. They are saved to a Skills folder in your OneDrive and are for your personal use.
  • Organization skills your IT team deploys.
Before you start: sign in with your work account and save practice files to OneDrive. Skills are still rolling out, so menu names and built-in skills may differ in your apps. If you do not see them, your organization may not have them enabled yet.

02 · Anatomy of a skill

Each custom skill is a folder that contains one file named SKILL.md. The file has two parts:

  1. Frontmatter between two --- lines. It holds the name and a description that tells Copilot when to use the skill. Required.
  2. Body with your instructions: the steps and what a good result looks like. No formatting rules.
The rule people miss: the folder name must exactly match the name in the file. A skill named store-results-review lives in a folder named store-results-review. Use lowercase words joined with hyphens.

03 · Create a skill
MethodBest forHow
Describe itExcel; fastest startType @skill-builder and describe the task. Copilot drafts the skill, lets you preview and refine it, then saves it to OneDrive.
Record itPowerPoint; repeated formatting tasksSelect + › Choose skills › Manage plugins & skills › Add skill › Record Skill. Do the task, select Stop, review the draft, and select Upload.
Paste itA skill you already wroteIn PowerPoint, select Add skill and paste the SKILL.md text into the form, or upload a skill file.
Save to OneDriveAny app that supports skillsIn the Copilot pane, select … › Manage plugins & skills › Custom skills › Create OneDrive folder › Open skills folder. Add a folder with a SKILL.md file, then select Refresh.
Write a great description. Start with “Use when I ask…” and name both the trigger and the result. Copilot reads the description to decide when the skill applies.

Step 2 · Build a custom skill with skill-builder

What and why: creates a reusable skill from a plain-language description.

@skill-builder Create a custom skill named store-results-review. Use it when I ask to review store results. Steps: add a column named Percent of Target that divides Q3 Sales by Q3 Target, formatted as a percentage with no decimals; highlight rows below 100% of target in light red; sort by Percent of Target from lowest to highest; then summarize the results in three bullets that describe patterns only, without claiming causes. Show me the draft before saving.

Tip: Review the preview and tighten the description if it is vague, then save. If skill-builder is not available yet, use the ready-made SKILL.md below.

Alternative · Ready-made SKILL.md

What and why: the same skill, ready to save in a folder named store-results-review inside your OneDrive skills folder.

---
name: store-results-review
description: Use when I ask to review store results. Adds a Percent of Target column, highlights stores below target, and sorts from lowest to highest.
---
# Review store results

## Steps
1. Make sure the data is formatted as an Excel table.
2. Add a column named Percent of Target that divides Q3 Sales by Q3 Target. Format it as a percentage with no decimals.
3. Highlight rows below 100% of target in light red.
4. Sort the table by Percent of Target from lowest to highest.
5. Summarize the results in three bullets. Describe patterns only; do not claim causes.

Tip: Save it as a plain-text file named exactly SKILL.md, then select Refresh in Custom skills.

Step 3 · Use your skill

What and why: runs your saved steps with one short request.

@store-results-review Review the store results in this table.

Tip: Undo (Ctrl+Z) reverses Copilot edits like any other change. Run the skill again on next quarter’s data to see the payoff.

05 · Skills in PowerPoint

Use a skill: in the Copilot prompt box, select + › Choose skills, or type @ and the skill name.

Set up the practice deck

Create a blank presentation, save it to OneDrive, open Copilot, and send this prompt.

Step 1 · Create a practice deck

What and why: gives you a deck to test your skill on.

Create a five-slide presentation titled Holiday Readiness Update for store leaders, using only these fictional facts:
- 8 of 12 practice stores met or beat their Q3 sales target.
- Return rates were highest at the 4 stores that have not completed training.
- Focus areas: finish training at the 4 remaining stores, share weekly product tips, and review return reasons weekly.
- Next step: store leaders confirm team training plans by Friday.
- Not decided yet: launch dates, staffing changes, and budget changes.
Keep each slide to four bullets or fewer.

Tip: Review the draft. A few slides are enough for practice.

Step 2 · Add a custom skill

What and why: adds a skill by pasting it into the Add skill form.

---
name: leadership-takeaways-slide
description: Use when I ask for leadership takeaways. Adds one slide at the end of the deck with three key takeaways and one clear ask, matching the existing design.
---
# Add a leadership takeaways slide

## Steps
1. Read the whole presentation.
2. Add one new slide at the end titled Leadership Takeaways.
3. Write exactly three takeaways, each 12 words or fewer, using only facts already in the deck.
4. Add one line at the bottom that starts with "Our ask:" and states the next step from the deck.
5. Match the fonts, colors, and layout of the existing slides.
6. If the deck does not state a next step, write "Our ask: not stated in this deck" instead of guessing.

Tip: Select + › Choose skills › Manage plugins & skills › Add skill, paste this text, and select Add.

Step 3 · Use your skill

What and why: runs the skill on your deck.

@leadership-takeaways-slide Add leadership takeaways to this presentation.

Tip: If the skill does not appear, select Refresh in Custom skills and confirm the folder name matches the skill name.

Try recording: select Add skill › Record Skill, then restyle a slide title and a bullet list by hand. Select Stop once the changes appear, review the draft, and upload it. Recordings must be under 10 minutes, and actions in other apps are not captured.

06 · Skills and Word

As of October 2026, Microsoft has documented the skills picker for Excel and PowerPoint, but not yet for Word. Check your Word Copilot pane: if you see Choose skills, the steps above apply. If not, reuse your skill as a step-by-step prompt with Edit with Copilot.

  1. Open a Word document saved to OneDrive.
  2. Open Copilot, select Tools › Edit with Copilot, and send the prompt below.
  3. Review the suggested changes before keeping them.

Skill-style prompt for Word

What and why: applies the same “steps plus result” structure that a skill uses.

Follow these steps on this document: 1. Add a section at the top titled Executive Summary. 2. Summarize the document in one short paragraph and no more than five bullets. 3. Use only facts already in the document. 4. Add a final line that starts with "Open questions:" and lists anything the document leaves undecided, or write "Open questions: none stated." Do not change the rest of the document.

Tip: Keep prompts you reuse in a note so they are ready to become skills when Word supports them.

07 · Tips and tricks

Build better skills

  • One skill, one repeatable outcome.
  • Write numbered steps and describe what “done” looks like.
  • Tell the skill what to do when information is missing, such as “write not stated.”
  • Test it on fresh data, then tighten the wording.

Manage them well

  • Turn a skill off in Manage plugins & skills to stop automatic use. In Excel, you can still call it with @.
  • Rename the folder to hide a skill without deleting it.
  • Select Refresh after changing files in OneDrive.
  • Never put passwords or confidential data in a skill file.

Copy-ready follow-up · “Are you sure?”

What and why: after a skill runs, asks Copilot to confirm it followed every step.

Are you sure? Check your last result against every step in the skill you used. List each step as done or not done, show any number or statement that is not supported by this file, and fix anything you missed. Do not guess.

Tip: A self-check can still miss errors. Spot-check key numbers yourself.
