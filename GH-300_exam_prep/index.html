GH-300 is the intermediate Microsoft certification for GitHub Copilot. Tell this site when you are sitting the exam and it builds a day-by-day plan that fits the time you actually have.

Step one: your exam date

This one date drives the countdown, study-plan length, daily tasks, and practice-exam schedule.

The scoring trap that costs people points

Passing is 700 on a scaled 1–1000 range. That is not 70% correct. Microsoft weights questions by difficulty and does not publish the raw-to-scaled conversion.

Scores on this site are readiness estimates only. Use the domain breakdown to decide what to fix next.

What changed

GH-300 used to be a GitHub/PSI exam. It moved into Microsoft Certifications and is now delivered by Pearson VUE from the Microsoft Learn registration flow.

Do not study from old logistics. The current exam is Microsoft-administered, proctored, 100 minutes, and scored on the Microsoft scaled-score model.

The useful non-facts

If a source gives a real-exam question count or a fixed exam price, treat it as a guess. Microsoft publishes neither for GH-300.

Retakes and renewal

Retake policy

  • After a first failure, wait 24 hours.
  • After later failures, wait 14 days between attempts.
  • Maximum five attempts in a 12-month period.
  • There is no free retake. You pay for each retake.

Renewal

Certifications of this type renew annually through a free Microsoft Learn renewal assessment. Renewal is unproctored, open book, and available in the six-month window before expiration.

Treat renewal as maintenance, not another full proctored exam.

Domain 1 — Use GitHub Copilot responsibly

15–20%. Risks, principles, harms, mitigation, and validation.
1

Responsible use

Fairness, reliability and safety, privacy and security, inclusiveness, transparency, and accountability. The exam asks for judgment, not slogans.
L

Limitations

Code quality, language and framework specificity, dependency on training data, and complex problem solving.
V

Validate output

The safe answer keeps a human accountable: review, test, scan, and verify before trust.

Domain 2 — Use GitHub Copilot features

25–30%. The largest domain.
IDE

IDE and CLI

Inline suggestions, ghost text, next edit suggestions, chat, Ask, Edit, Agent mode, and the standalone GitHub Copilot CLI.
P

Platform features

Copilot cloud agent, code review, PR summaries, Spaces, custom instructions, prompt files, custom agents, skills, hooks, and MCP servers.
MCP

Replacements matter

Copilot Extensions were retired and replaced by MCP servers. Knowledge bases were retired and replaced by Copilot Spaces. Learn the mapping.

Domains 3 and 4 — Data, architecture, and prompting

20–30%. The process questions.
3

Seven-step data flow

HTTPS, context gathering, proxy filtering, toxicity filtering, LLM generation, post-processing, delivery, and repeated prompts.
28

Retention and training

Editor prompts are discarded after a suggestion returns. Chat outside the editor, CLI, Mobile, and GitHub.com are typically retained 28 days.
4S

Prompt engineering

Single, Specific, Short, Surround. Add context, use examples, manage chat history, and know zero-shot, one-shot, and few-shot prompting.

Domains 5 and 6 — Productivity, privacy, and safeguards

20–30%. How teams use and govern Copilot.
5

Productivity

Generation, refactoring, documentation, learning, modernization, tests, edge cases, assertions, security, and performance improvements.
6

Content exclusions

Business and Enterprise only. Exclusions affect suggestions, chat context, and code review, but not symlinks, remote filesystems, or indirect IDE semantic information.
P

Policies and audit

Within one enterprise, least restrictive usually wins. Across different enterprises, most restrictive almost always wins. Audit logs do not include local prompts.

Verify the current Microsoft Learn certification page before you sit the exam. Confirm the exam code, the 100-minute limit, the Pearson VUE delivery path, and the scaled 700 passing score.
